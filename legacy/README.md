# legacy/

`pyqt-client/` is the original PyQt6 desktop pet from
[Evelynall/ASoul-Little-Bun](https://github.com/Evelynall/ASoul-Little-Bun) (GPL-2.0, used with the author's permission),
imported unchanged (apart from the move) as the starting point of this project.

It is kept **for reference and attribution only**. It is no longer the client of AsoulTappo and is not maintained here:
the active client is the Tauri 2 + Vue 3 app in [`../client`](../client). Its `update_checker.py` / `updater*.py` still point at the upstream repository.
