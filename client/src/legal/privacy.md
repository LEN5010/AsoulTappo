# 隐私政策

更新日期：2026 年 11 月 13 日

AsoulTappo（以下称本软件）是 LEN5010（以下称我们）个人开发的非官方粉丝作品。本政策说明本软件及官方联机服务处理的信息类型、使用目的、对其他用户的公开范围，以及你管理这些信息的方式。

## 一、适用范围

本政策适用于本软件客户端，以及本软件默认连接的官方服务器（len5010.top/tappo）。如你将服务器地址更改为第三方搭建的服务器，该服务器对信息的处理由其运营者负责，不适用本政策。

## 二、在本机处理的信息

- 键盘、鼠标和手柄输入：本软件通过全局输入监听读取三类信息：按键的按下与松开状态、鼠标按键的左右区分、鼠标移动的方向和距离，用于桌宠动画和敲击计数。
- 设置和登录凭证：你的设置、存档码和 Asasfans 登录凭证保存在本机，用于在下次启动时恢复桌宠状态和存档。
- 运行日志：本软件在本机记录运行状态和错误，内容包括系统和浏览器内核版本、显示器缩放、每分钟的按键、点击和移动次数，以及当时前台程序的文件名、是否全屏、是否以管理员身份运行。日志保存在本机，你可以在设置页导出日志，并自行决定是否提供给我们。
- 录制窗口：录制窗口在独立的普通窗口中显示桌宠，供直播和录屏软件捕获画面。

## 三、发送至官方服务器的信息

联网使用时，本软件向官方服务器发送以下信息：

- 存档码：本软件首次启动时在本机随机生成存档码，用于识别你的存档。服务器保存由存档码计算得出的存档编号。
- 敲击次数和在线状态：本软件定时上报一段时间内的敲击总次数和在线状态，用于计算碎片收益、统计每日活跃用户和识别连点器。
- 游戏数据：抽卡结果、持有的卡片和物品、碎片变动记录，以及签到、刮刮乐和猜拳记录。
- 展示信息：昵称、角色、佩戴的铭牌、展示卡，以及是否参与收藏榜。
- 客户端版本号：用于判断是否需要更新及兼容旧版本。
- 访问记录：服务器的访问日志记录请求来源的 IP 地址、请求时间和访问的接口，用于排查故障和防范攻击。

## 四、对其他用户公开的信息

- 联机房间：同一房间的成员可以看到你的昵称、角色、铭牌、你选择的状态、敲击次数、发送的表情和猜拳结果，以及桌宠的实时动作（按键是否按下、按下的鼠标按键、爪子位置），并可查看你的展示卡和收藏进度。公开房间会在房间列表中显示房主的昵称和角色。
- 全服收藏榜：上榜后，所有玩家可以看到你的昵称、角色、铭牌、收藏分，以及卡片、大隐藏和皮肤的数量，并可查看你的展示卡和收藏进度。昵称经过屏蔽词处理。在官方服务器上，仅绑定 Asasfans 账号的存档参与排名。你可以在设置中关闭上收藏榜。

## 五、Asasfans 账号

Asasfans 账号的注册和登录由 Asasfans 主站（len5010.top）处理：你的用户名、邮箱、密码和邮箱验证码直接发送至主站，由主站保存。桌宠服务器保存账号编号与存档的绑定关系。验证登录时，桌宠服务器向主站查询你的账号信息，并在内存中短暂缓存。

## 六、第三方服务

- GitHub：检查和下载更新时，本软件访问 GitHub 的发布页面，GitHub 将获得你的 IP 地址等网络信息，相关处理适用 GitHub 的隐私政策。
- 除 GitHub 外，本软件使用的服务均由我们运营。你的信息仅用于本政策所述目的，并在法律法规要求时依法提供。

## 七、保存和删除

- 存档和游戏数据保存至你申请删除，或官方联机服务停止运营时为止。
- 删除本机数据：卸载本软件时选择删除应用数据，或手动删除本软件的数据文件夹。
- 删除服务器上的存档、解除 Asasfans 绑定：请发送邮件至 len5010@qq.com 并说明需要删除的存档；游客存档请附上存档码，以便确认存档归属。我们将在 15 个工作日内处理。

## 八、信息安全

本软件与官方服务器之间通过 HTTPS 加密传输。存档码是存档的唯一凭证，请妥善保管。

## 九、未成年人

未满 14 周岁的未成年人，应在监护人同意和指导下阅读本政策并使用本软件。

## 十、政策更新

本政策更新后，本软件将在启动时请你重新阅读并确认。

## 十一、联系我们

如对本政策有任何疑问，或需要查询、更正、删除你的信息，请发送邮件至 len5010@qq.com。
