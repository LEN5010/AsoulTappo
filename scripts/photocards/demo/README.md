# 小卡材质页和开盒动画

两个独立网页，不随客户端发布。客户端的实现在 `client/src/photo`，是从这里移植过去的，两份代码各自独立，改一边不会影响另一边：

- `index.html`：材质页，一张一张看卡面。选卡、翻面、关掉材质、看签名怎么写。
- `open.html`：开一盒 20 张的动画。卡片组成是固定的样例（15 张单人、1 张签名、3 张双人、1 张团体，顺序随机），和游戏里的概率无关。

图片、卡片清单和音效都读客户端的（`client/src/assets`、`client/src/data/manifest.json`，路径在 `catalog.js`），所以要从仓库根目录起一个静态文件服务，再打开 `/scripts/photocards/demo/open.html`。

## 开盒流程

1. 盒子落下，点一下打开，敞着口挪到左边，银袋立在里面。
2. 每次从盒里抽出一袋到中间。翻盖盖在袋口前面，按住往上拉就揭开，抓的那一侧先起来；松手后停在原处，拉过 72% 自动揭完。点一下自动揭，空格和回车相同。
3. 揭翻盖时袋里的光从翻盖下沿漏出来，卡上有几个人就有几种应援色，按卡面上站的位置从左到右各占一段；签名卡是金光。刚揭开一条缝时都是灰白的光，揭到三成左右颜色分开。光的大小跟着揭开的程度走，手停光也停。揭完袋口打开，光变成向上散开的光柱，一人一道，卡从光里露出背面再抽出来，袋子放下时光熄掉。强弱依次是单人、双人、团体、签名，参数在 `scene.js` 的 `GLOW`。单人的光弱而短，不停顿；单人卡自己翻面，再点一下收走；按住上下来回划会连着揭，节奏随速度变快。
4. 双人和团体卡：揭的时候桌面就开始变暗、染上这几种颜色；揭完袋子往下沉一点，光柱先立起来（双人约 0.5 秒、团体约 0.75 秒，团体的光里有浮尘），卡再抽出来、转平、翻面，光留在卡身后，颜色还是各在一边。途中点一下会加速。
5. 签名卡：金光最强，有浮尘；停留和团体一样，卡慢一些抽出，翻面和靠近是一个动作，正面刚转过来笔就起了，签名写 1.8 到 2.0 秒，写完有一道光顺着墨走过。翻面途中按的不算；开始写 0.45 秒以后点一下直接写完，再点一下收走；写完后可以拖着转。连撕键也会停下来写完。
6. 稀有卡收进底下那排时抬高一点。20 张开完一起摊开，普通的先到，双人、团体、签名依次最后；点一张放大看，拖着可以转到任意角度，松手后停在正面或背面，再点一下放回去。
7. 连撕键自动开完整盒。系统开了减少动态效果时直接摊开 20 张，签名直接显示写好的。

## 文件

- `open/scene.js` 流程、手势、每帧状态和绘制顺序；`open/shaders.js` 着色器；`open/gl.js` WebGL2 的薄封装；`open/sound.js` 音效。撕袋声由 `pack-open.m4a` 的起音切片拼成。
- 卡面材质取自 `index.html`：开盒页运行时读出它的片段着色器 `FRAG` 改写成 ESSL 300，两边保持一致。改 `FRAG` 会同时影响两页；里面的新变量名不能和 `shaders.js` 的 `cardFs` 里的重名，重名只会在开盒页报错。
- 光：颜色取应援色，按最亮的通道提亮后再取 1.8 次方加深，免得照在银膜上都发白。`FOIL_FS` 里的 `u_glow` 照亮翻盖内侧、刚揭开的膜面、袋口内侧；`SLIT_FS` 是翻盖下沿漏出的光，`BEAM_FS` 是袋口的光柱，`LIGHT` 是它们和桌面、背光、卡面共用的取色。膜不透光：揭的时候只有缝下面那一截膜面被照亮。
- 普通的静态文件服务不发缓存头，浏览器会把没怎么改动的文件缓存几个小时。开盒页读 `index.html` 用 `no-store`，模块加载前用 `reload` 重取；改回去会出现流程是新的、卡面着色器是旧的。

## 调试参数

`?seed=13` 固定顺序，`?first=group-1` 指定第一张，`?first=diana-3-sign` 指定第一张是签名卡，`?first=tiers` 让前四张依次是单人、双人、团体、签名，`?first=sign` 让前三张是三位成员各一张签名卡，`?skipintro` 跳过盒子，`?motion` 忽略系统的减少动态效果，`?dpr=1` 固定像素比，`?manual=1` 停掉时钟，由 `window.demo` 逐步推进（无头浏览器检查用）。

## 动作的约定

不震屏、不强闪、不回弹。补间只用三种缓动：`out`（阻尼弹簧，快起慢收）、`quick`（更短）、`flow`（两头都慢）。新动作会接住物体当时的速度，中途改目标不会顿一下。一段动作里按一下，后面整段加速。

银袋的尺寸（袋身 62×90 毫米，翻盖 18 毫米）、卡在袋里背面朝外、盒子背面和顶面的印刷没有实物依据。
